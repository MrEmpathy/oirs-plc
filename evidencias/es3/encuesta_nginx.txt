## 4. Casos de envío (POST /api/respuestas)
Respuesta válida                         {"ok":true}  → HTTP 201
Trampa para bots (honeypot) completada    {"error":"No fue posible registrar su respuesta. Intente más tarde."}  → HTTP 400
Establecimiento inexistente               {"error":"No fue posible registrar su respuesta.","detalle":["Establecimiento inválido."]}  → HTTP 400
Datos personales en las respuestas        {"error":"No fue posible registrar su respuesta.","detalle":["La encuesta es anónima: no se aceptan datos personales."]}  → HTTP 400
JSON mal formado                          {"error":"Solicitud inválida"}  → HTTP 400
Envío desde otro sitio (Sec-Fetch-Site)  {"error":"Origen no permitido"}  → HTTP 403
Método GET                               {"error":"Método no permitido"}  → HTTP 405
Ruta de la API no expuesta                  → HTTP 404
Cuerpo mayor a 8 KB                         → HTTP 413
Respuestas en MongoDB: antes 20, después 21 (solo se guardó la válida)
